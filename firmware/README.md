# 参考固件（ESP32-S3 + WS2812B）

这是 `SKILL.md` 里说的那套自研固件的完整实现。串口协议和 `assets/strip_console.py`
是**成对绑定**的：这套固件配这个控制台，改一边要同步改另一边。

## 硬件假设

| 项 | 值 | 在哪改 |
| --- | --- | --- |
| 主控 | ESP32-S3，N16R8（16MB Flash + 8MB OPI PSRAM） | `platformio.ini` |
| 数据脚 | GPIO 4 | `main.cpp` 的 `DATA_PIN` |
| 颜色顺序 | GRB | `main.cpp` |
| 灯带 | 5V 的 WS2812B 兼容灯带 | 见 SKILL.md 三条硬约束 |
| 灯珠数 | 不写死在代码里，用串口命令 `n<数字>` 改 | 运行时 |

**不依赖任何第三方灯带库**（不用 FastLED / Adafruit NeoPixel）。灯带的时序由程序自己
用 RMT 或 SPI 直接打，所以编译很快，也方便改波形去排查闪烁。

## 编译烧录

```bash
pio run -e esp32-s3-devkitc-1 -t upload
pio device monitor -b 115200
```

烧录会独占串口。如果用配套控制台，先 `curl -s http://127.0.0.1:8770/api/quit` 放开串口，
烧完再把控制台拉起来。

## 串口命令（115200，每条后面回车）

| 命令 | 作用 | 存 NVS |
| --- | --- | --- |
| `n<数字>` | 灯珠数量（1~300） | 是 |
| `b<数字>` | 亮度 0~255 | 是 |
| `c<RRGGBB>` | 设单色，并自动切到"纯色常亮" | 是 |
| `f<0~18>` | 直接选灯效编号 | 是 |
| `0`~`7` | 快捷灯效 | 是 |
| `z<数字>` | 只点亮第 N 颗（定位用） | 否 |
| `a<RRGGBB>` | `z` 用的颜色 | 否 |
| `t` | 自检：红 → 绿 → 蓝 → 白 | 否 |
| `w` | 显示 Wi-Fi 热点信息 | 否 |
| `?` | 帮助（含当前全部设置） | 否 |
| `k<0/1>` | 首颗启动缓冲（不吃灯珠） | 是 |
| `g<0/1>` | 第一颗红绿对调 | 是 |
| `m<毫安>` | 电流上限，`0` = 不限 | 是 |
| `s<1~8>` | 呼吸快慢，`1` 最慢（约 4.1 秒） | 是 |
| `d0~d3` | 数据脚驱动电流（5 / 10 / 20 / 40 mA） | 是 |
| `p0~p3` | 波形档（只在老 RMT 方式下有用） | 是 |
| `x0` / `x1` | `x0` 老 RMT 分包（每 6 颗一道缝）；`x1` 整帧直发（默认） | 否 |
| `h<0~64>` | SPI 帧头起跑缓冲字节数 | 否 |
| `y<1500~10000>` | 数据速度 kHz（默认 2500） | 否 |
| `r<1~5>` | 同一帧连发几遍 | 否 |

## 灯效编号（共 19 个）

| # | 名字 | # | 名字 |
| --- | --- | --- | --- |
| 0 | 彩虹流动 | 10 | 跑马灯 |
| 1 | 逐颗扫描 | 11 | 双色追逐 |
| 2 | 整条呼吸 | 12 | 彩虹流星 |
| 3 | 彗星来回 | 13 | 星星闪烁 |
| 4 | 全白长亮 | 14 | 篝火 |
| 5 | 整体变色 | 15 | 警灯 |
| 6 | 关灯 | 16 | 彩虹波浪 |
| 7 | 纯色常亮 | 17 | 斑马纹（排查用） |
| 8 | 纯色呼吸 | 18 | 参考灯（排查用，前 4 颗红绿蓝白） |
| 9 | 彩虹呼吸 | — | 单颗定位（只能由 `z` 进入） |

**17 / 18 / 单颗定位 是排查专用**，画面完全静止、逻辑极简。它们的作用是把
"电路问题"和"动画问题"分开——别删，这是整套方案最值钱的部分。

## 诊断固件 `src/diag.cpp`

跟主固件是两个独立的编译目标，**不会**被一起编进主固件
（`platformio.ini` 里两个 env 各用 `build_src_filter` 只选一个文件）。

```bash
pio run -e diag -t upload
pio device monitor -b 115200
```

它只干一件事：**量出灯带那一头到底有没有电**，不用万用表。

原理是灯带数据输入脚（Din）内部有一个对 +5V 的保护二极管。用芯片内部的弱上拉
（约 45kΩ）去顶这根线，然后读电压：

| 读数 | 含义 |
| --- | --- |
| ≈3300mV 且三个时间点都不涨 | 灯带有 5V，二极管不导通 |
| ≈700mV 左右，且 5ms / 50ms / 300ms **一路往上涨** | 灯带没电，电容在被慢慢顶起来（独有指纹） |
| 一直是 0mV | 线被短路 |
| 一上来就是 3300mV，不涨 | 线是空的（没接负载） |

固件里同时读了两个对照脚：`GPIO6`（空脚，标准答案）和 `GPIO48`（板载灯那根线，
那颗灯已知是亮的），拿它们跟 `GPIO4` 比对，一眼看出区别。

> 用的是芯片内部弱上拉，**探的是"有没有 5V 和 GND"，不是测数据信号质量**。

## `arduino/minimal_test/minimal_test.ino`

35 行的最小验证程序，用 FastLED 写，跟本固件无关，只用来快速确认
"接线 / 供电 / 引脚配置"这三件事——红→绿→蓝→白每颗依次点亮，然后全灭重来。
先跑通这个再上主固件，能省掉大量怀疑人生的时间。

## `main.cpp` 顶部的注释已和代码对齐

文件头现在列的是**实际生效**的命令：`f<0~18>` 选灯效、`s` 呼吸快慢、`m` 电流上限、
`k` 首颗缓冲、`g` 红绿对调、`z` 单颗定位、`a` 改定位颜色，以及排查用的
`x` / `h` / `y` / `r` / `p`。

特别标了一件事：**快捷键 `0`~`7` 的编号和灯效编号差一位**——
`1`=彩虹流动、`2`=逐颗扫描、`3`=整条呼吸、`4`=彗星来回、`5`=全白长亮、
`6`=整体变色、`7`=纯色常亮、`0`=关灯。这个差一位是代码里写死的，第一次用必踩。

> 改这次只动了注释，代码部分重新编译验证过（`[SUCCESS]`，RAM 14.7% / Flash 11.7%）。
> 不过**最权威的清单永远是板上发一个 `?` 打印出来的那份**，它读的是运行时实际状态。

## 电流估算

单颗 WS2812B 全白最亮约 60mA。电源容量 `电流 ≥ 灯珠数 × 60mA × 0.8`。

67 颗的实测参考：

| 场景 | 估算电流 |
| --- | --- |
| 全白 @255 | ≈4020 mA |
| 全白 @150 | ≈2365 mA |
| 全白 @100 | ≈1576 mA（实测吻合） |
| 彩虹流动 / 呼吸 @114 | ≈300~900 mA |
